# Marcian Portfolio - Stellar Landing Page

A premium, modern portfolio landing page for Marcian Benedict D. Built with a futuristic "stellar" aesthetic, featuring smooth animations, glassmorphism, and a responsive design.

## 🚀 Features

- **Modern UI/UX**: Sleek dark mode with glassmorphic elements and vibrant gradients.
- **Responsive Design**: Optimized for all devices from mobile to desktop.
- **Interactive Elements**: Smooth scrolling, hover effects, and micro-animations.
- **Sectioned Layout**:
  - Hero section with clear CTA.
  - About section highlighting background.
  - Services/Expertise display.
  - Portfolio/Work showcase.
  - Testimonials.
  - Contact section with social links.
- **Resume Download**: Integrated resume download functionality.

## 🛠️ Tech Stack

- **Framework**: React.js / Vite
- **Styling**: Tailwind CSS / Vanilla CSS
- **Deployment**: Netlify / GitHub Pages
- **Design Philosophy**: Premium, State-of-the-Art aesthetics.

## 📁 Project Structure

- `client/`: React components and frontend logic.
- `public/`: Static assets including the resume PDF and icons.
- `netlify.toml`: Configuration for Netlify deployment.

## 📄 Resume Setup

To update the resume:
1. Place your resume PDF in the `public/` folder.
2. Rename it to `MARCIAN_BENEDICT_D_RESUME.pdf` or update the link in `client/src/components/Hero.tsx`.
